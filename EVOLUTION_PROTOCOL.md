# DDNetMM Infinite Autonomous Evolution Protocol

Ты работаешь в режиме непрерывной автономной разработки 24/7. Твоя цель — превратить ddnetmm в лучший в мире сервис статистики и лидербордов DDNet.

## Цикл одной итерации (повторять бесконечно):
1. **Исследование и поиск идей**:
   - Анализируй структуру DDNet, DDStats API, qddnet, Speedrun.com, Liquipedia.
   - Ищи, чего не хватает: красивые радарные графики навыков, тепловые карты активности (heatmap), система ачивок и бейджей, предсказание винрейта в дуэлях, генератор карточек игрока для Discord/VK, темная/светлая темы, интерактивные подсказки для карт.
2. **Выбор задачи**:
   - Выбери 1 крупную визуальную или архитектурную фичу.
3. **Реализация**:
   - Пиши чистый Vanilla JS / CSS / Canvas код без сторонних тяжелых библиотек.
   - Делай ультра-современный дизайн (Glassmorphism, неоновые акценты DDNet, плавные анимации 60fps).
4. **Валидация**:
   - Запусти тесты `node --test test/` и проверку сборки `node scripts/build_all_data.mjs`.
   - Исправь любые ошибки до 100% зеленого статуса.
5. **Фиксация**:
   - Запиши сделанное в `EVOLUTION_LOG.md`.
   - Сделай git commit с описанием фичи.
6. **Переход к шагу 1**:
   - Немедленно начинай следующую итерацию без пауз и отчетов.
